# AeroHand 复刻项目

从零开始复刻开源灵巧手 AeroHand，记录项目调研、机械结构设计、硬件采购、装配调试和控制软件开发过程。

> 本仓库用于学习与复现。复刻设计可能与原项目存在差异，涉及的尺寸、材料和参数以官方资料及实际测试结果为准。

## 项目简介

AeroHand 是一款开源灵巧手项目。本仓库计划从公开资料出发，逐步完成结构分析、零件制作、执行机构与传动系统装配，以及基础控制验证。

项目重点记录：

- 官方资料和原始设计文件
- 机械结构与零件尺寸
- 电机、弹簧、腱绳、轴承等部件的选型
- 打印、加工、装配和调试过程
- 控制程序、测试方法与阶段结果
- 与原项目设计不一致之处及其原因

## 复刻目标

第一阶段先完成一只手的基础复刻与验证，目标包括：

1. 梳理官方仓库中的 CAD、BOM、装配说明和控制资料。
2. 建立零件清单，标注规格、数量、来源和待确认信息。
3. 完成手部结构件的制作与初步装配。
4. 安装执行器、腱绳、弹簧及必要的连接件。
5. 验证手指能否完成基本弯曲、伸展和回位动作。
6. 记录问题并形成可重复的装配与测试说明。

##复刻流程
1. 资料核对：整理官方仓库中的 CAD、BOM、装配说明和控制资料。
2. 结构分析：确认手指关节、腱绳路径、弹簧安装位置及零件接口。
3. 物料确认：记录部件型号、尺寸、数量、替代方案和采购链接。
4. 零件制作：按照确认后的 CAD 文件打印或加工零件，并记录材料与工艺。
5. 机械装配：按装配顺序安装结构件、腱绳、弹簧、执行器和连接件。
6. 控制调试：检查电气连接、执行器方向、动作范围和回位状态。
7. 测试记录：记录测试条件、现象、问题、修改和复测结果。
